# Актуальная схема базы данных

В этой директории хранится актуальная схема БД проекта.

## Файлы

- `schema.sql` — последняя выгрузка схемы (таблицы, индексы, ограничения).

## Как схема получена

- СУБД: PostgreSQL 16.
- Источник: постоянная БД на TEST-стенде
- Команда выгрузки:

      pg_dump --schema-only --no-owner --no-privileges -U <пользователь> <имя_бд> > db/schema/schema.sql

Если БД работает в Docker:

      docker exec <контейнер> pg_dump --schema-only --no-owner --no-privileges -U <пользователь> <имя_бд> > db/schema/schema.sql

## Когда обновлять

При каждом изменении структуры БД. Новый `schema.sql` коммитится в той же ветке и в том же Pull Request, что и изменение кода, которое потребовало это изменение.

## Правила

- `schema.sql` не правится вручную, только перевыгрузкой.
- В файле нет данных (INSERT/COPY), паролей и других секретов.
- В Git хранится один актуальный файл. История изменений видна через `git log`.
- Файлы миграций сюда не кладутся, у них своя папка.

## Как применить схему

      psql -U <пользователь> -d <имя_бд> -f db/schema/schema.sql
